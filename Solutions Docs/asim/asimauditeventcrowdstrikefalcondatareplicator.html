Description

Normalizes CrowdStrike_Audit_Events_CL to the ASIM Audit Event schema, including configuration, policy, account, file, share, and device audit operations. Only event_simpleName identifies operations; records with an empty value are excluded. Unknown event names map to Other. Undocumented numeric enumerations are retained without guessing their meanings. Missing device or object values remain empty. Use pack=true to retain original source fields, including currently empty columns. The source-IP prefix parameter in the filtering parser supports IPv4 prefixes. This parser was created using the agentic ASIM parser creation tool, powered by Skills in GitHub.
