## Description

This ASIM parser supports normalizing Halcyon DNS activity events to the ASIM DNS normalized
schema. These events are generated by Halcyon's DNS-based threat detection and ingested into the
HalcyonEventsV2_CL table in Microsoft Sentinel.

Note: The HalcyonEventsV2_CL table must be configured on the Log Analytics workspace's Analytics plan to use this parser. The Basic Logs plan does not support invocation of user-defined functions, which is required for ASIM parser consumption.
