The SentinelOne V2 data connector ingests Activities, Agents, Groups and Threats logs from the SentinelOne REST API, and security alerts from the SentinelOne Unified Alert Management (UAM) GraphQL API, into Microsoft Sentinel. It is built on the Microsoft Sentinel Codeless Connector Platform and uses DCR-based ingestion-time transformations. See: SentinelOne UAM GraphQL API

Setup Instructions

⚠️ Note: These instructions were automatically generated from the connector's user interface definition file using AI and may not be fully accurate. Please verify all configuration steps in the Microsoft Sentinel portal.

1. Connect SentinelOne to Microsoft Sentinel

Configure your SentinelOne API connection. Each instance corresponds to a single SentinelOne Management URL + API Token.

Configuration steps for the SentinelOne API

Follow the instructions below to obtain the credentials. Alerts are collected via the SentinelOne Unified Alert Management GraphQL API.

1. Retrieve SentinelOne Management URL

1.1. Log in to the SentinelOne Management Console with Admin user credentials. 1.2. In the Management Console copy the URL link without the URL path.

2. Retrieve API Token

2.1. Log in to the SentinelOne Management Console with Admin user credentials. 2.2. In the Management Console, click Settings. 2.3. In Settings view click on USERS. 2.4. In the USERS page click on Service Users -> Actions -> Create new service user. 2.5. Choose Expiration date and scope (by site) and click on Create User. 2.6. Once the Service User is created copy the API Token from the page and press Save.

3. Connect new instances

To enable the SentinelOne connector for Microsoft Sentinel, click the Add new instance button, fill in the required information in the context pane and click on Connect. Connector Management Interface
