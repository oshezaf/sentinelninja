The QCrypton PQC Scanner data connector provides the capability to ingest post-quantum cryptography readiness findings from your Azure environment into Microsoft Sentinel through the QCrypton API. Findings include Key Vault key posture (RSA/ECC vs. PQ-hybrid), TLS certificate signature algorithms on public endpoints, Storage Account and App Service TLS configuration, and CMK provenance.

Setup Instructions

⚠️ Note: These instructions were automatically generated from the connector's user interface definition file using AI and may not be fully accurate. Please verify all configuration steps in the Microsoft Sentinel portal.

1. Connect QCrypton PQC Scanner to Microsoft Sentinel This connector polls the QCrypton PQC Scanner API to retrieve post-quantum cryptography readiness findings and ingest them into the PQReadiness_CL table in your Log Analytics workspace.

1. API Key

Obtain your QCrypton API key from the QCrypton Portal. Navigate to Settings > API Keys and generate a key with read access to scan findings.

2. API Server URL

Enter the base URL of your QCrypton API server. The default is https://api.qcrypton.com. If you use a dedicated or regional instance, enter the URL provided by QCrypton.

  • QCrypton API Server URL: https://api.qcrypton.com
