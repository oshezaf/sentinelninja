Solution Folder SpyCloud Enterprise Protection CCF

The SpyCloud Enterprise Threat Protection solution for Microsoft Sentinel ingests SpyCloud breach watchlist and catalog data via the Codeless Connector Framework (CCF), including an optional Compass daily feed. The solution includes three built-in analytic rules, two KQL parsers, and three automation playbooks covering Microsoft Defender for Endpoint response, Azure AD / Entra ID Conditional Access enforcement, and sign-in session revocation.

Underlying Microsoft Technologies used:

This solution takes a dependency on the following technologies, and some of these dependencies either may be in Preview state or might result in additional ingestion or operational costs:

a. Codeless Connector Framework (CCF)

b. Azure Logic Apps

c. Microsoft Defender for Endpoint
