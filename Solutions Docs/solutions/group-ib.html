The Group-IB Threat Intelligence solution for Microsoft Sentinel connects the Group-IB Threat Intelligence platform to Microsoft Sentinel with Azure Logic Apps playbooks. Scheduled collector playbooks poll the Group-IB TI collections and deliver two kinds of content: threat indicators (IP addresses, domains, URLs and file hashes) uploaded to Microsoft Sentinel Threat Intelligence as STIX 2.1 objects, and context records (threat actor profiles, APT and hacktivist reports, malware intelligence, vulnerabilities, leaked credentials, compromised cards and public leaks) written to Log Analytics custom tables through the Logs Ingestion API. Enrichment playbooks, triggered from an incident or an entity, add Group-IB IOC search, WHOIS and IP scoring results as incident comments.

Playbooks: 26 scheduled collectors, 1 indicator-processor playbook that all indicator collectors batch into (deploy it first), 3 incident-triggered and 7 entity-triggered enrichment playbooks.

Prerequisites: a Group-IB Threat Intelligence subscription with API access (username and API key).
