The Datadog solution for Microsoft Sentinel enables you to ingest Datadog Audit Trail events through the Datadog Audit API. These events provide visibility into administrative activity, configuration changes, access, and security-relevant actions in the Datadog platform.

Underlying Microsoft Technologies used:

This solution takes a dependency on the following technologies, and some of these dependencies either may be in Preview state or might result in additional ingestion or operational costs:

a. Microsoft Sentinel Codeless Connector Framework

b. Azure Monitor Logs Ingestion API
