## Schema (18 columns)

**Source:** [Connector definition](https://github.com/Azure/Azure-Sentinel/blob/master/Solutions/QCryptonPQCScanner%5CData%20Connectors%5CQCryptonPQCScanner_CCF/PQReadiness_Table.json)

| Column Name | Type | Description |
|:------------|:-----|:------------|
| Algorithm | string | Cryptographic algorithm in use (e.g., RSA, EC, ML-KEM). |
| AssetIdentifier | string | Unique identifier for the specific cryptographic asset (e.g., Key Vault key URI, certificate thumbprint). |
| AssetKind | string | Classification of the cryptographic asset (kv-key, kv-cert, tls-cert, tls-config, storage-encryption, cmk). |
| Curve | string | Elliptic curve name if applicable (e.g., P-256, P-384). Null for non-EC keys. |
| ExpiresOn | datetime | Expiry date of the certificate or key. Null for non-expiring assets. |
| KeySize | int | Key size in bits (e.g., 2048, 4096). Null for non-key assets. |
| Location | string | Azure region of the scanned resource. |
| Metadata | string | Additional JSON metadata about the finding. |
| PostureReason | string | Human-readable explanation for the quantum posture classification. |
| QuantumPosture | string | Quantum readiness posture: vulnerable, partial, or quantum-safe. |
| ResourceGroup | string | Resource group containing the scanned resource. |
| ResourceId | string | Azure Resource Manager resource ID of the scanned resource. |
| ResourceName | string | Display name of the scanned Azure resource. |
| ResourceType | string | Azure resource type (e.g., microsoft.keyvault/vaults, microsoft.web/sites). |
| RiskScore | int | Numeric risk score (0-100) reflecting quantum vulnerability severity. |
| SignatureAlgorithm | string | Signature algorithm of the certificate (e.g., SHA256WithRSA, ECDSAWithSHA384). |
| SubscriptionId | string | Azure subscription ID containing the resource. |
| TimeGenerated | datetime | Timestamp when the finding was generated by the scanner. |
