This query identifies AI agents that are shared with the entire organization (SharedWith contains "*"). Such configurations significantly increase the risk of unauthorized access by unintended users, which could lead to data exposure or misuse of agent capabilities. Broad sharing is especially sensitive when the agent has access to sensitive data sources, tools, or credentials. Recommended Action: Review these agents to confirm whether organization-wide sharing is necessary for the business scen
