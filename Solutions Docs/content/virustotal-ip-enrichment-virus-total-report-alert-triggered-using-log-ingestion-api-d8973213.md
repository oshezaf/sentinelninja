# IP Enrichment - Virus Total Report - Alert Triggered using Log Ingestion API

This playbook will take each IP entity and query VirusTotal for IP Address Report (https://developers.virustotal.com/v3.0/reference#ip-info). It will write the results to Log Analytics and add a comment to the incident. This playbook sends VirusTotal results to the `VirusTotalIPReport_CL` table via the Logs Ingestion API, instead of the older `VTIPReport_CL` table.
