# URL Enrichment - Virus Total Report - Incident Triggered using Log Ingestion API

This playbook will take each URL entity and query VirusTotal for info (https://developers.virustotal.com/v3.0/reference#url-info). It will write the results to Log Analytics using the Azure Monitor Logs Ingestion API. This playbook sends VirusTotal results to the `VirusTotalURLReport_CL` table via the Logs Ingestion API, instead of the older `VTURLReport_CL` table.
